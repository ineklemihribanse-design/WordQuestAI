This file is a **review queue only**. It has no Turkish meanings, no guaranteed single-word compatibility and is **not packaged as playable bilingual vocabulary**. It must not be added to the 2,000-per-level tally.

Future accepted entries in `approved_en_tr_176.tsv` require human-approved English forms, Turkish senses and provenance. Import script rejects duplicate headwords within a level, malformed rows, unlicensed/uncited rows and original game-record collisions. English–Turkish translations must be checked for meaning, word class, ambiguity and actual difficulty; there is no claim of official CEFR certification.

The existing WordQuest 1.0.75 A1–C1 addendum retains its original EnglishPractice / CEFR-J / Octanove attribution and CC BY-SA 4.0 conditions. Baseline game words remain unchanged.
