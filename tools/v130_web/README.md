# Hybrid pilot
Opt-in Web Lobi from native lobby; same signed app, session, room, local records and Firebase callbacks. A signed HTML snapshot changes layout and web logic without package installation. WebView is isolated with no JavaScript interface, network, storage, file access or external navigation. Only an exact main-frame user-gesture HTTPS action URI can call the fixed native callbacks; host and readiness are checked again. No tokens, account passwords, IDs or local paths passed to web page. Native fallback on failure. A separate 1.0.131 HTML snapshot demonstrates larger cards; not yet published. This is a pilot, not a migration of all screens. Native code or new permissions still need APK. The HTML contains web JavaScript, not Android executable code. Validate and device-test before publication.
