# Original reading and beginner practice
20 independently authored reading passages (40 questions) and 32 beginner-level questions. Source syllabus: Remzi Hoca Question Types Set 1, including reading comprehension, sentence completion, connectors and grammar. All passages and questions are newly written, not source transcriptions. Difficulty is an editorial estimate; a human language review is required. Arena uses five options; the YDS Academy receives the 40 YDS-level reading items under its existing four-option contract. Arena selects at most one question per passage within a match.
