# v1.0.150 learning expansion (development)
206 independently glossed academic headword candidates and 53 original five-option questions; the Academy subset contains 41 YDS-level questions. User PDFs guide the syllabus: 60 Günde YDS Kelimeleri, Dilsem 4000 vocabulary, Remzi Hoca Question Types, Me Too 40x40, İrem modules 1/3/4 and Hakkı Şahin grammar notes. No source PDF, publisher question or passage is redistributed. Difficulty mappings are editorial estimates, not certified CEFR levels. General licensed extension: up to 200 single words per available A1–C1 level, from the existing CC BY-SA 4.0 list, see ../v175/content/ATTRIBUTION.md. The original APK dictionary remains checksum-pinned. Android Academy retains its four-option contract; Arena uses five. Filtered Arena matches retain the original filtered lexical generator. Device tests and teacher review remain required. No paid services added.

Second expansion: 61 additional independently authored non-translation questions, 492 contextual variants from 41 existing original grammar patterns with a fifth distractor; these are practice variants, not independent grammar rules. The full compatible licensed vocabulary is now included instead of a 200-per-tier cap. No repeated grammar pattern within one match. Actual unique count and Workers Free size require CI verification.
Android Academy includes the 61 new standalone questions as well (102 authored additions total); the 492 grammar variants are Arena only, since their original four-choice versions already exist in the Academy. Filtered Arena can use contextual vocabulary questions only when the exact answer matches a word in the selected filter. Other question families remain excluded for filtered games.
