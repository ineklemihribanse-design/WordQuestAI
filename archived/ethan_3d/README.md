# WordQuest AI — Archived 3D Ethan (v1.0.41)

The **entire recoverable 3D application snapshot** is retained on Git branch
`archive/ethan-3d-v1.0.41` (from successful signed release v1.0.41).

This is an archival decision, **not deletion**:
- Original Ethan human glTF/GLB reconstruction source code and pinned licensed
  upstream sources remain in tools/v1271, v130, v134, v137–v141 on the archive branch.
- Exact binary GLBs are regenerated by its original build workflow and are
  checksummed in the off-APK `source/archived-teachers/ethan-3d-v1.0.41/MANIFEST.json`
  during the new 2D build.
- The new 1.0.42 app deliberately ships **no** Ethan 3D GLB assets, Filament/
  SceneView dependency, or 3D launcher/activity.
- Prior user data is **not deleted**. Internal legacy `Mert` actor ID and
  `ethan_thread_ids` database namespace are kept for compatibility with
  existing conversations and encrypted user preferences.
- To resume the original Ethan experiment later, create a new feature branch
  **from the archive branch** rather than resetting or uninstalling WordQuest AI.

## Product decision (17 November 2026)
Replace frustrating native 3D teacher visual with a **semi-realistic 2D,
waist-up human** named Alex. Main teacher screen retains real Gemini/OpenAI
dialog, TTS voice start/stop, text-range driven seven mouth expressions, small
calm hand gestures, listening/thinking/speaking states, and US/UK voices.
The normal WordQuest learning modes remain unchanged.

The first 2D test version is code 67 / `1.0.42-realistic-2d-live-teacher-qa`.
Its human quality, mouth/gesture alignment and device performance still need
real Android comparison rather than claims based on Gradle compilation alone.
